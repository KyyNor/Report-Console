# ADR 0001：开发过程使用 RC 本地检查点

状态：已采纳

## 决策

项目目录继续由 SVN 管理。Report Console 不在项目目录创建 `.git`，而是在应用本地保存开发检查点：SQLite 保存时间线和文件清单，内容使用 SHA-256 去重并压缩放在应用数据目录。

检查点仅覆盖 `project.yaml`、受管 JSX、过程定义与 `meta/` 源文档。MJS/CPT 是可重建产物，传统 CPT 不受 RC 管理，数据库操作不可由检查点自动回滚。

## 原因

业务目录可能已经是 SVN 工作副本，把第二个版本控制元数据写入其中会增加冲突和维护成本；但 Agent 的每轮开发又需要可见 Diff 与可恢复的中间状态。

## 后果

恢复检查点会修改工作区源码，因此 SVN 会把它视为普通本地改动；恢复前必须自动保留“恢复前检查点”。检查点默认不随项目目录迁移，如需迁移过程历史，后续提供独立导出/导入能力。
