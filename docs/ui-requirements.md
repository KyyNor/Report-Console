# 项目工作台 UI 需求文档（供设计 agent 出原型）

> 目标读者：UI/UX 设计 agent。本文自包含，不依赖其他对话上下文。
> 交付物预期：桌面端（Electron，目标窗口 1380×880，最小 1024×700）三栏工作台的**高保真原型图**。
> 请勿改动「已锁定决策」章节的内容；视觉风格、布局比例、组件形态由你提案。

---

## 1. 产品背景（一段话）

Report Console 是帆软（FineReport）加壳开发控制台：把「数据库（建表/存储过程）→ 数据接口（`_data.cpt`）→ 页面（jsx → cpt）」三层报表开发收进一个桌面应用，统一管理、原地构建、实测验证，并内置 AI Agent 代劳开发。现正从「按资源类型分六个页面」重组为「**项目制 + 三栏工作台**」。

## 2. 已锁定决策（不可改）

| # | 决策 |
|---|---|
| D1 | 顶层组织单元是 **Project（项目）**，绑定一个文件目录；项目可绑定**多个数据库连接**（连接来自应用内注册表，一条连接 = 一个 MySQL 连接，名字与帆软数据连接一致） |
| D2 | **数据接口**归属单一项目（不共用），构建为项目目录 `data/` 下的一个 `_data.cpt`，页内每个数据集各自携带所属连接名 |
| D3 | **存储过程**直接绑定项目；一般在本项目内创建，需要复用其他项目的某个过程时走**关联**（引用，不复制） |
| D4 | 项目目录三分：`data/`（数据层产物）、`pages/`（页面源码与产物）、**元数据目录**（存储过程创建语句、项目需求文档、项目设计文档） |
| D5 | 工作台为**左中右三栏**：左栏选项目；中栏浏览项目资源；右栏对选中资源操作 |
| D6 | 页面产物由 jsx 编译（esbuild → 净化 → 注入骨架 → .mjs + .cpt），构建必须过**质量门**（error 拒绝落盘）——UI 必须呈现质量门结果，不得提供绕过入口 |
| D7 | Agent 与手工操作共用同一工具链与质量门；右栏可**带上下文唤起 Agent** |

## 3. 三栏信息架构

### 3.1 左栏 —— 项目选择器

内容（按优先级）：

- 项目列表：项目名（= 目录名）、绑定连接的 badge 列表、资源规模摘要（接口 n / 过程 m / 页面 k）
- 当前选中项目的高亮态
- 新建项目入口（向导或弹窗：名称、绑定目录、勾选多个连接）
- 次要操作：项目设置（改绑定连接、改注释）、删除项目（需确认）
- 顶部或底部：全局环境状态（帆软 / MySQL 各连接 / reportlets 可写性，红绿点 + 延迟）

状态：无任何项目（首次使用引导：新建 / 从目录扫描导入）；项目目录缺失（目录被移动/删除的警告态）。

### 3.2 中栏 —— 项目资源浏览器

资源按类分组（分组可折叠），建议四组：

1. **数据接口**（每项展示：接口名、类型 tag〔列表/统计/单条/字典/增/删/改〕、**所属连接 badge**、最近实测结果〔err_code=0 绿 / 失败红 / 未测灰〕、最近构建时间）
2. **存储过程**（每项展示：过程名、归属〔本项目创建 / 关联自其他项目 + 来源项目名〕、最后修改时间、注释摘要）
3. **页面**（每项展示：页面名、**staleness**〔cpt 落后于 jsx 需重建 / 最新 / 从未构建〕、大小）
4. **文档（元数据）**（项目需求、设计文档、存储过程创建语句等文件；名称 + 类型 + 修改时间）

通用能力：按名称搜索过滤；组内排序；各组头部有该组的主操作（如「新建接口」「新建过程」「新建页面」「新建文档」）。

状态：选中项目的空态（每组给出引导性空态文案）；某连接不可达时对应接口的实测状态显示「连接不可达」而非笼统失败。

### 3.3 右栏 —— 资源操作面板

选中中栏某项后，右栏展示详情 + 操作。按资源类型：

**数据接口**
- 详情：契约信息（参数表 name/type/default、SQL 代码——只读展示 + 「编辑」进入 CodeMirror）
- 操作：编辑契约 → 保存（幂等 upsert）；**构建数据层**（重建 `_data.cpt`，展示质量门 findings：error/warning 分级列表 + 构建日志）；**实测**（用默认参数打真实接口，展示 err_code / 行数 / 耗时 / 响应 JSON，历史可回看）；删除（确认）
- 一键验收：构建 + 实测模块内全部接口（verify）

**存储过程**
- 详情：完整 `CREATE PROCEDURE` 定义（CodeMirror SQL，可编辑）
- 操作：**应用**（DROP IF EXISTS + CREATE，需确认，审计落库）；**试执行 CALL**（可编辑 CALL 语句，真实执行，展示结果 JSON）；**关联其他项目的过程**（选择器：项目 → 过程）；解除关联；新建过程（从模板起步，模板约定返回 `SELECT JSON_OBJECT(...)`）

**页面**
- 详情：jsx 源码（CodeMirror javascript，高亮编辑）
- 操作：保存；**构建**（展示管线日志与质量门 findings；失败时 .mjs 保留、.cpt 不落盘的说明）；**预览**（帆软 `op=write` URL，独立窗口或外部浏览器打开）；从脚手架新建（blank / list / form）；删除（连带 .mjs/.cpt，需确认）

**文档（元数据）**
- 详情：Markdown 渲染 + 源码编辑双模式（需求/设计文档）；SQL 源码（过程创建语句）
- 操作：新建 / 重命名 / 编辑 / 删除

**通用（所有资源类型）**
- **「用 Agent 做」入口**：唤起 Agent 面板（右栏内 tab 或覆盖层，由你设计），自动携带上下文（当前项目、资源类型与名称、关键代码片段），用户输入自然语言指令；会话中需可视化：流式文本、工具调用名与参数摘要、工具结果状态、可中断
- 历史侧栏/抽屉：该资源的构建历史、测试历史、（过程）审计记录

## 4. 核心交互流（原型需覆盖的场景图）

1. **冷启动**：首次打开 → 无项目引导 → 新建项目（选目录、勾选连接）→ 进入空工作台
2. **日常开发**：左栏选中项目 → 中栏点一个接口 → 右栏改 SQL → 构建 → 质量门 3 warning 0 error → 实测 err_code=0 → 中栏该接口状态变绿
3. **失败路径**：构建出现 error → findings 列表定位问题 → 修改 → 重建通过
4. **页面全流程**：新建页面（list 脚手架）→ 编辑 jsx → 构建 → 预览（帆软窗口打开）
5. **Agent 代劳**：右栏点「用 Agent 做」→ 输入"给这个页面加一个导出按钮"→ 观察工具调用流 → 完成后资源状态刷新
6. **共用存储过程**：新建接口需要写操作 → 关联其他项目已有的 `sp_xxx` → 接口 SQL 里 CALL 该过程
7. **多连接场景**：项目绑定 A、B 两个连接 → 多数字接口走 A，一个字典接口选 B → 构建后 `_data.cpt` 内各数据集连接名正确

## 5. 全局导航（开放，欢迎提案）

已定方向：应用整体导航收拢为五个入口——**总览 / 项目（即本工作台）/ 连接（注册表管理）/ Agent / 设置**。侧边栏 or 顶栏、工作台是否全屏沉浸（左栏可折叠成项目切换器）等由你提案。原「数据接口 / 存储过程 / 页面」三个独立视图取消。

## 6. 视觉基调（参考，可提案）

- 现有实现：React 18 + antd 5（主色 #1677ff）、CodeMirror one-dark 代码区
- 建议延续 antd 生态与中文界面；代码/契约信息密度高，注意等宽字体与状态色（绿=通过 / 红=失败 / 黄=警告 / 灰=未测或不可达）
- 存储地颜色语义（如有全局图例可沿用）：SQLite 账本=蓝、reportlets 产物=紫、MySQL=青、帆软服务=黄

## 7. 边界与约束

- 三栏在 1024px 最小宽度下必须可用（可折叠策略）
- 所有破坏性操作（DROP+CREATE、删除资源、试执行 CALL）需二次确认
- 质量门结果（findings）是高频信息，需要在右栏有稳定、可扫读的呈现方式
- 连接不可达 / 帆软不可达时：浏览与编辑仍可用，仅构建/实测/预览禁用并说明原因
- Agent 中断、超时、错误的事件呈现

- 全局导航提案（1–2 个方向）
- 标注清楚每块区域的信息来源与交互（能对应到本文 3.x 的编号最好）
