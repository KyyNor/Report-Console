# 文件上传、下载与导出

## 当前平台能力

Report Console 目前没有业务附件上传、附件下载或统一导出接口。项目 `meta/` 的“导入文档”仅用于把用户选择的开发文档复制进项目上下文，不是业务页面的上传能力。

因此，当需求涉及业务文件时：

1. 先确认是业务附件上传、已有附件下载，还是报表/数据导出。
2. 不要猜测 HTTP、SFTP、对象存储或帆软内部接口，也不要在 JSX 中硬编码未确认的地址、凭据或文件路径。
3. 如未提供已验证的业务接口或公共 CPT，应停下说明缺少的运行时能力，而不是伪造实现。

## 将来统一接入时的建议

- 业务附件上传：使用平台提供的公共 overlay CPT（Modal + iframe）或受控上传 API；业务页只传业务标识与文件归属标识。
- 附件下载：由后端/公共 CPT 返回受鉴权的下载地址；前端只触发已提供的下载动作。
- 报表或数据导出：明确导出格式、数据范围、权限和异步任务状态；不要把浏览器中的当前表格数据当作完整导出结果。

在这些能力落地并通过验证前，Agent 可以完成页面入口和交互占位，但必须清楚标注“依赖待接入的文件服务”，不得声称上传或下载已经可用。
