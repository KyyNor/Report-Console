# 移动端页面验收

移动端验收关注“移动 SPA 生命周期 + 触控体验”，不能只复用桌面端检查结论。

## 自动检查

- `build_page` 必须通过移动专属质量门：无 PC `antd`、无 iframe、无 `window.__*` 自定义赋值，CPT 只能由移动骨架生成。
- `open_page` 必须使用移动入口，并检查 data 请求 4xx/5xx 与 JavaScript error。
- 数据接口仍以 `err_code=0`、返回行数和契约匹配为准。

## 人工观察

- 375px 左右宽度下无横向溢出；长文本、空状态、加载态、错误态可读。
- 按钮、列表项可触达，底部操作不被安全区遮挡。
- Popup/Dialog/ActionSheet 能打开、关闭，浏览器返回行为符合预期。
- 从一个移动报表切换到另一个报表后仍能加载，不能因为遗留全局状态卡死。

## 已知边界

移动 SPA 的多个页面共享同一个 `window`。不要反复用 `FR.remoteEvaluate` 做自动探测；它在部分移动环境中可能挂起。需要公式求值时应显式触发、记录结果并允许失败回退。
