# 列表页面模式

## 前置条件

先读取相关数据接口契约；列表接口应已实测通过。页面只能按契约调用 `/api/data`，参数必须是 `{ name, type, value }` 数组，业务分页使用 `p_page`、`p_pagesize`。

## 推荐结构

1. 筛选区：维护筛选状态；点击查询时页码重置为 1。
2. 表格区：`Table` 绑定加载状态、行数据和稳定的行 key。
3. 分页区：分页变更后重新拉取列表；总数来自独立统计接口。
4. 行操作：查看、编辑、删除按实际需求提供，破坏性操作必须二次确认。

查询失败时保留用户输入并展示明确错误，不要把失败误显示成空列表。

## 数据刷新

新增、编辑或删除成功后，重新读取当前筛选条件和当前页的数据；如果删除导致当前页为空，可回退到上一页后再查询。

复杂编辑或选择器需要跨页面时，继续读取 `page_interaction` Skill。
